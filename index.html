01 Selected Work

Five projects, in the order I would talk about them.

01

CO-Zero — car-cabin CO monitor

A carbon monoxide detector for private car cabins, built so exposure is caught before it turns dangerous. The ESP32 reads an MQ-2 and a DHT22, smooths the signal with a moving average, and applies hysteresis to the alarm thresholds before driving an OLED and a buzzer. Readings publish over MQTT and land in a live Python dashboard. Ten test scenarios and sixty assertions ship with it.

  • ESP32
  • MQ-2
  • MQTT
  • Python
  • Plotly

02

InLET lab web profile

The public profile and content system for the Information and Learning Engineering Technology lab at Polinema, built by a team of four in our third-semester PBL. Native PHP with an MVC structure over PostgreSQL: guestbook, lab loan and visitation records, publication and product counts, student attendance, news, and an admin CMS. I owned the backend and database — most of it the admin panel — plus the CMS front end in Tailwind, and ran QA before handoff.

  • PHP
  • PostgreSQL
  • MVC
  • Tailwind CSS

03

Aqua Monitoring — estuary water quality

A water quality prediction app for Coding Camp 2026, built with a full-stack and AI team. I handled the data end to end: collection, assessment, cleaning, imputation, and exploratory analysis. Then feature engineering, training and comparing prediction models for quality classification, and an interactive Streamlit dashboard to present the results.

  • Python
  • Pandas
  • scikit-learn
  • Streamlit

Data Science · Team2026

04

Evently — guest and QR check-in

A guest and check-in platform for events. Seven-table PostgreSQL schema with migrations, ENUM types, indexes and an ERD, plus end-to-end check-in using unique tokens, real-time validation, duplicate-scan prevention and audit logging. I also built the three-tier RBAC, the event approval workflow, CRUD for guests, events, templates and scanners, Excel/CSV/PDF reporting, a live attendance dashboard, and a Node.js service for bulk WhatsApp messages.

  • PostgreSQL
  • Node.js
  • RBAC
  • QR check-in
